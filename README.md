# 🎯 Number Guessing Game

A simple command-line Number Guessing Game built using Python.

## 📖 Description

This project is a command-line game where the computer randomly selects a number between 1 and 100. The player keeps guessing until the correct number is found. The game provides hints if the guess is too high or too low and counts the number of valid attempts.

## ✨ Features

- Random number generation
- Input validation
- Attempt counter
- High or low hints
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run:

bash
python number_guessing_game.py
